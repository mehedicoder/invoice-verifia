### **Invoice Verifia:** 

#### AI-Powered Document Workflow

This project is a Java-based automated 
invoice processing system built on the 
langgraph4j framework. It demonstrates 
a hybrid "Human-in-the-Loop" architecture
where low-value invoices are handled by 
an autonomous agent, while high-value 
documents are routed for manual authorization.
